# SEPEX Email Signature Builder

سازنده امضای ایمیل سپکس — اپلیکیشن React برای ساخت امضای HTML دوزبانه (فارسی / انگلیسی) مطابق قالب رسمی SEPEX.

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه production:

```bash
npm run build
npm run preview
```

## قابلیت‌ها

- فرم ورود اطلاعات شخصی (نام، سمت، تلفن، داخلی، موبایل، ایمیل)
- پیش‌نمایش زنده امضا در دو زبان فارسی (RTL) و انگلیسی (LTR)
- خروجی HTML سازگار با کلاینت‌های ایمیل (جدول + استایل اینلاین)
- کپی با یک کلیک
- راهنمای نصب برای Gmail، Outlook، Apple Mail و Thunderbird
- رابط کاملاً ریسپانسیو و دوزبانه

## تکنولوژی

- React 19
- TypeScript
- Vite 8
